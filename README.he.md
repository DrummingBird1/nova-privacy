## מה זה Nova Homepage?

Nova מחליף את עמוד הטאב החדש של Chrome בדשבורד אישי ורגוע: שעון, מזג אוויר, המשימות שלך, טיימר פומודורו ושורת חיפוש חכמה — הכל במקום אחד. כל ווידג'ט הוא אופציונלי, כל צבע ורקע ניתנים להתאמה אישית, והכול עובד ב-13 שפות עם תמיכת RTL מלאה.

המאגר הזה מארח את האתר הציבורי של הפרויקט (README זה, [דף הנחיתה](https://drummingbird1.github.io/nova-privacy/), ו[מדיניות הפרטיות](https://drummingbird1.github.io/nova-privacy/privacy.html)) דרך GitHub Pages. הוא **לא** מכיל את קוד המקור של התוסף עצמו.

## פיצ'רים

- 🕐 **שעון וברכה** — 12/24 שעות, עם ברכה אישית לפי שעת היום
- 🎯 **מיקוד יומי** — מטרה עיקרית אחת להיום, מתאפסת כל בוקר
- 🔍 **חיפוש חכם** — Google / Bing / DuckDuckGo / Brave / מנוע מותאם אישית, השלמה אוטומטית, מחשבון וממיר יחידות מובנה (`12*30`, `5 km to miles`), וקיצורי `!bang`
- 🌤️ **מזג אוויר חי** — דרך Open-Meteo, לפי מיקום או עיר, עם תחזית ל-3 ימים
- ✅ **משימות** — עדיפויות, תאריכי יעד, תת-משימות, משימות חוזרות, גרירה לסידור מחדש
- 🔥 **מעקב הרגלים** — רצף יומי עם תצוגת 7 ימים
- 🍅 **טיימר פומודורו** — משכי מיקוד/הפסקה מותאמים, צלילי רקע, התראות רקע אמיתיות
- 📝 **פתקים** — פתקים מרובים עם תמיכת Markdown
- 💹 **טיקר קריפטו**, 🌍 **שעוני עולם**, ⏳ **ספירות לאחור**, ⚡ **גישה מהירה** לסימניות וטאבים אחרונים
- 🎨 **התאמה אישית מעמיקה** — ערכות נושא עם תצוגה מקדימה חיה, גרדיאנטים, תמונות Unsplash, העלאת תמונה משלך, צבעי הדגשה, מצב קומפקטי, מצב זן
- ⌨️ **פלטת פקודות** (`Ctrl/Cmd+K`) לניווט מהיר
- 🌍 **13 שפות** עם תמיכת RTL מלאה: אנגלית, עברית, צרפתית, ספרדית, גרמנית, רוסית, ערבית, פורטוגזית, יפנית, קוריאנית, סינית, הינדי, איטלקית
- 🔒 **100% מקומי** — סנכרון הגדרות רק דרך ה-`chrome.storage.sync` שלך; שום דבר לא נשלח אף פעם לשרת של Nova, כי אין כזה

## התקנה

Nova Homepage עדיין לא בחנות האינטרנט של Chrome — הוא בפיתוח פעיל. בדקו את [האתר החי](https://drummingbird1.github.io/nova-privacy/) למצב העדכני.

## פרטיות

כל הנתונים שלכם — הגדרות, משימות, פתקים, הרגלים — נשארים על המכשיר שלכם (`chrome.storage`) או מסתנכרנים רק דרך חשבון ה-Google שלכם עצמכם, דרך הסנכרון המובנה של Chrome. ל-Nova אין שרת אחורי ואין אנליטיקס. מזג אוויר, מחירי קריפטו ותמונות רקע נשלפים ישירות מהספקים שלהם (Open-Meteo, CoinGecko, Unsplash) רק כשהפיצ'רים האלה מופעלים. פרטים מלאים: [מדיניות הפרטיות](https://drummingbird1.github.io/nova-privacy/privacy.html).
